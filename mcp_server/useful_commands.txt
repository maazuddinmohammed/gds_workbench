
# Deploy To Web App


```
az webapp deploy \
  --resource-group "<RESOURCE_GROUP>" \
  --name "<APP_SERVICE_NAME>" \
  --src-path "mcp_server/dist/gds-mcp-appservice-0.2.0-role-fix.zip" \
  --type zip \
  --restart true \
  --track-status true
```

```
az webapp deploy \
  --resource-group "gds_etl_workbench" \
  --name "gds-test-workbench" \
  --src-path "gds-mcp-appservice-0.2.0-role-fix.zip" \
  --type zip \
  --restart true \
  --track-status true
```

```
az webapp restart \
  --resource-group "gds_etl_workbench" \
  --name "gds-test-workbench"
```

```
psql "host=<POSTGRES_HOST> port=5432 dbname=meta_ai user=<ADMIN_USER> sslmode=require"
```

```
az webapp auth show \
  --resource-group "gds_etl_workbench" \
```
