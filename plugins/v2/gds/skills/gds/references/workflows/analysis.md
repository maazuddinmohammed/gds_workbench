# Analysis

Use physical metadata, Profiles, existing Analysis, and Assertions to investigate grain, keys, overlaps, relationships, and data-quality signals.

Loop over every selected input and important cross-system pair. Record evidence-backed findings, confidence, and supporting endpoints. A finding may be inference-only. Populate measured validation fields only from actual deterministic results; never partially populate a measured group or fabricate numbers.

Classify each selected input represented, context-only, excluded with reason, or blocked. Analysis advises later models; it does not silently create model structure.
