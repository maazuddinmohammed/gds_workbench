## Semantic ownership and delegation

One modeling owner reconciles grain, identity and relationships across phases. Workers investigate bounded questions or review candidates. Their handoff includes evidence, contradictions, limits and the next useful investigation. Keep current decisions in object-analysis notes; the owner inspects actual results rather than accepting phase-completion claims.


Respect existing user authorization and the saved policy; delegate only when useful. Read `status.subagent_policy` first. If absent, resolve and persist the user's choice: **Inherit current model** (omit a model override), **Disable subagents**, or **Fixed model** (exact user-supplied name). Never infer a fixed model, substitute, or silently fall back. If unavailable, ask for a revised choice. Delegation does not change Stage, lock, or Apply boundaries.
