# Business-domain knowledge

Load when a business rule affects a modeling decision. No marketplace-specific or Tenant-specific business-rule pack is bundled yet. Plugin marketplace installation rules are unrelated to business marketplace semantics.

First inspect applicable Model Assertions, current definitions, supplied approved documentation and recorded decisions. State unknown rules and ask only about decisions that affect the requested outcome. Names, common industry practice and another Tenant's model are hypotheses, not authority.

A reusable rule must identify its source, owner, applicable domain/Tenant/Model scope, version or effective date, exceptions and review status. Link the evidence; do not copy private source dumps. Verify applicability before reusing it. Conflicting evidence requires resolution, not silently choosing the most recent-looking text.

Add a domain reference and a link here only when approved reusable knowledge is actually available and maintaining it is within the request. Universal naming/key conventions remain in the existing [naming](../model/naming.md) and [key/audit](../model/keys-and-audit.md) guides. Request-specific decisions stay in bound task evidence or suitable governed Assertions.
