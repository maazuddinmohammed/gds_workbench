# Change impact format

Use in current task evidence; derive it from current records rather than maintaining another workflow ledger.

- Requested before/after behavior and exact selected records.
- Bound applied revision, Snapshot inputs and pending-change digest.
- Definite dependencies and why they are affected.
- Possible dependencies needing semantic or runtime review.
- Unchanged reusable, protected and unknown items.
- Authorized edit scope; additions requiring a decision.
- Checks and post-Apply evidence needed to confirm the result.

Explicitly state incomplete dependency coverage. Names, file timestamps and Model revision changes alone cannot establish impact.
